# Mollah Pro Zone Ai — Developer AI Studio

A beautiful, coding-first AI chat studio powered by Google's Gemini API.

## Features
- 💻 **Code mode** — elite senior-dev system prompt, strongest coding model auto-selected
- 💬 Chat mode, 🖼️ Image generation mode
- 📁 **Save to device** — pick a folder on your device; every code block from the chat is written as files (File System Access API)
- 🔑 **Bring your own key** — your Gemini API key stays in your browser's localStorage only. It is never in the code or repo.

## Use
1. Open the site.
2. Paste your Gemini API key in the sidebar (get one free at https://aistudio.google.com/apikey) → Save key.
3. Pick a model (strongest auto-selected) and start building.

## Security
Never commit an API key to this repo. If a key was ever exposed, revoke it in Google AI Studio and create a new one.

## Deploy
Static site — served via GitHub Pages from the `main` branch root.
